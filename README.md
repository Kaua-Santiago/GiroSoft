
# 💙 Girosoft

### Sistema de gestão para barbearias

**Seu talento faz o corte. A Girosoft faz a gestão.**

A Girosoft é um sistema web desenvolvido para
facilitar a administração de barbearias.

## 🚀 Funcionalidades

- Gerenciamento de clientes
- Cadastro de serviços e preços
- Agendamento de horários
- Calendário de agendamentos
- Dashboard com indicadores
- Relatórios financeiros
- Autenticação de usuários

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Supabase
- PostgreSQL

## 🎯 Objetivo

Simplificar a gestão de barbearias com uma
solução moderna, intuitiva e eficiente.

## 👨‍💻 Desenvolvimento

Projeto desenvolvido para aplicar conhecimentos
de desenvolvimento web, banco de dados e
autenticação de usuários.
